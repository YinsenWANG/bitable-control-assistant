# 发布插图源文件

这些 HTML 是使用虚构数据绘制的布局示意，用于公开说明投影会议场景，不是客户飞书表格截图。顶部栏隐藏复用扩展的 content.css；其余表格、浏览器边框和详情控件用于展示布局，不能用来验证飞书兼容性。实际运行验证见 ../docs/TESTING.md。

从仓库根目录启动 `python3 -m http.server 8766 --bind 127.0.0.1`，打开 `/demo/comparison.html`、`/demo/detail.html` 或 `/demo/meeting.html`，视口设为 1280×800。示意页面不打入 Chrome 扩展 ZIP。

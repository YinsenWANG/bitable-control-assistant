BITABLE CONTROL ASSISTANT

把遥控器，设成你的习惯。

先在映射软件中设置按键组合，再在这里按一次对应按键。所有动作都可以修改。

会议演示

自动识别飞书多维表格，无需填写链接。TV 键进入全屏、自动收起侧边栏、隐藏文档顶部栏并开启遥控；再按一次退出会议，恢复窗口、顶部栏及原侧边栏状态。

Mac 如需隐藏标签页和地址栏，请在 Chrome「显示」菜单取消勾选「在全屏模式下始终显示工具栏」，只需设置一次。

从表格打开 GitHub 或切换到其他网站后，电源键仍能刷新当前页面。无需开启会议模式。

推荐使用这项跨标签页命令，新安装默认 Control + Shift + 8。请在 Chrome 扩展快捷键页面和遥控映射软件中设置相同组合键，以这里实际显示的值为准。Command + R / Control + R 仍可直接使用 Chrome 原生刷新；若遥控映射不稳定，可改用此命令。刷新遵循浏览器原生行为，请先处理未保存内容。

Home 键 · 回到会议表格

打开超链接或切换标签页后，一键回到正在会议模式的多维表格。

正在读取…

跨标签页快捷键由 Chrome 管理，也可以自定义。请将遥控器 Home 键映射成这里显示的组合键。新安装默认 Control + Shift + 0；升级后 Chrome 可能保留原组合键，请以此处显示为准。Chrome 未获得焦点时不生效。

麦克风 · 语音接入评论

保留「无线麦 + 微信输入法」的 Fn 设置。浏览记录详情时，按住麦克风说话；输入法完成这段识别后，自动展开评论并接入文字，无需先按菜单或 OK。

开启后，详情浏览时输入法输出的文字会进入评论，包括直接打字。编辑字段时先按 OK，文字仍写入该字段。会议模式关闭时不接收。请先在演示表验证；插件不录音、不提供语音识别，也不能感知 Fn 被按下的瞬间。

评论发送

控制发送成功后是否自动收起评论。

默认等待 1 秒；可设置 0–60 秒，支持小数，0 秒表示立即收起。期间开始输入新内容或手动操作评论时，评论会保持展开。

你的会议操作

列表：上下切记录，左右切视图，确定展开详情。详情：上下聚焦字段并滚动长文本，左右切记录，确定操作字段或在新标签页打开“超链接”字段中的链接。最后一个焦点是评论入口；也可绑定「展开评论并聚焦」。菜单键只展开或收起评论，不激活输入框；展开后按确定进入评论输入；音量按自定义步长连续缩放。退出会议后，底部提示会在 3 秒后消失。

返回键在输入框激活时只删除光标左侧字符，输入框为空、双击或长按都不会退出输入。非输入状态下，单按返回逐层收起评论、关闭详情；长按不会连续关闭多个层级。文字输入或选词时，方向键交给输入框。Home 键从其他标签页找回会议表格。电源键在上方「刷新当前标签页」中设置，可在其他网站使用。下方「刷新页面（备用）」保留原生刷新开关；关闭原生开关并录入自定义键时，这个备用动作仅在飞书内容区生效，有未发送评论时会先要求处理草稿。需要保留文字并退出输入时，可使用「退出输入 / 逐层返回（备用）」（默认 Esc），也可用菜单键收起评论。

语音键继续使用原来的输入法。开启上方「麦克风 · 语音接入评论」后，可保留 Fn 设置，语音识别结束后自动进入评论。扩展只接收输入法已经输出的文字，不录音，也不能检测麦克风按下的瞬间。其他支持组合键映射的设备也可绑定「展开评论并聚焦」（默认 Control + Shift + C）。文字落入评论框后，按确定发送。确认发送成功后，可按「评论发送」设置自动收起，默认等待 1 秒；期间开始新的输入或手动操作评论时保持展开。有草稿时，收起评论会保留输入框；切记录、切视图或关闭详情会先要求处理草稿。

安装或更新扩展后，请刷新飞书页面。Home 与电源由 Chrome 单独管理，导入 / 导出或「恢复默认按键」不会更改它们。其他录入的按键在多维表格内容区生效。

## 验证边界

后退缓存、后台重启、存储异常与恶意消息使用自动化模型测试，不代表所有飞书页面、系统或缓存条件的实测。支持重点是表格视图和标准卡片。实体遥控器 Home、电源和双击返回的确认沿用既有反馈；本版保留原自定义缩放。快速连按问题此前已由使用者在映射软件中解决。

两张设置图片来自同版设置 HTML 的本地预览；三张功能图使用虚构数据并标注，不作为真实飞书兼容证据。未代用户提交商店审核。

# v1.3.0 验证记录

日期：2026-10-23

## 本版验收

- 66 项自动检查及运行资源检查通过。新增检查覆盖：非飞书标签页刷新、不需要页面 URL、使用命令触发时的标签页避免焦点变化误刷、无可用标签或刷新失败处理、Chrome 实际快捷键显示与复制、修改后返回设置页更新键值、未分配快捷键时禁用复制。
- 真实 GitHub 页面通过 Mac 原生 Command + R 触发重新加载。未复现使用者此前的原生遥控映射失效，不将原因归咎于 GitHub 或映射软件。
- 使用者重新加载 v1.3.0，将电源键映射为 Control + Shift + 8 后，明确确认「新电源键能刷新 GitHub」。
- 新命令只通过 Chrome 重载触发命令时的标签页，不读取非飞书网站的内容或地址；manifest 没有新增权限。
- 本版未改动 v1.2.0 已验收的详情导航、缩放队列、顶部栏隐藏和提示栏计时。此前验收见下方记录。

## 图文与打包

- 商店两张设置截图来自本版真实 options.html 的本地预览，Chrome 命令列表与配置存储用示例值提供，未读取用户设置。
- 对比、会议和详情图为虚构数据的布局示意，图片及 README 均有标注。它们不是飞书现场截图，也不作为运行测试证据。
- 商店截图 / 示意图均为 1280×800 PNG；小型宣传图 440×280；图标 128×128。
- 运行 ZIP 根目录包含 manifest.json，排除测试、截图、示例页、内部链接和账号数据。

## 验证边界

当前主要验证 Mac Chrome、表格视图及标准详情卡片。其他遥控器、Windows、复杂输入法和自定义卡片仍可能需要适配。原生刷新及跨标签页电源命令遵循浏览器原生行为，不保证保留未提交的网页内容。Chrome 商店审核由平台决定；发布本版本不表示已上架。

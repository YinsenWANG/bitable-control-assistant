## v1.1.0 Chrome 示例页面

使用真实键盘事件，运行与发布包相同的适配器和按键处理代码；示例数据为虚构内容，Chrome 后台接口由测试页面模拟。

- 隐藏于零高度容器内的选项列表不再吞掉上下导航。
- 长文本按段滚动，到边界后进入下一个字段。
- 嵌在 contenteditable 里的链接通过字段容器持有键盘焦点，Enter 成功在新标签页打开对应网页。
- 菜单键收起评论，再按展开并聚焦。输入 ABC、左移并删除得到 AC；收起再展开仍保留草稿。
- 空评论框按 Backspace 先退出输入，再按收起评论。
- TV 退出会议恢复原来展开的侧边栏，再次开启会议折叠侧边栏。

## 真实飞书页面观察与已验证行为

在 v1.0.0 安装后验证了列表上下切记录、左右切视图、Enter 展开详情、详情左右切记录、字段进入编辑、输入时方向键不切记录、空评论框方向键和删除，以及当时的 Home 三层返回。连续三次缩放从 100% 到 130%，再连续恢复 100%。未在内部表格发送测试评论或更改字段内容。

该次实测发现折叠选项列表被误当作长文本，以及富文本链接被误当作输入状态；这些问题已在 v1.1.0 中修复，并加入回归测试与 Chrome 示例按键验证。

## 需要安装更新后复核

v1.1.0 的真实飞书整合验证、遥控器长按和系统语音输入法仍需在使用者加载后复核。浏览器工具禁止操作 Chrome 扩展管理页，重新加载必须由使用者手动完成。Home 的实际组合键以 Chrome 设置页显示为准。

Chrome Web Store 的审核结果由平台决定；本文件不表示扩展已经通过审核。

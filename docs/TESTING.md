# v1.5.1 验证记录

日期：2026-10-30。针对详情页左右切换记录后评论偶发自动展开的问题，新增 9 项回归检查，总计 155 项通过。新增场景中，有 4 项在修复前失败，可稳定复现用户反馈。

- 复用卡片并只更新字段 ID、直接替换卡片、记录 ID 暂时消失，以及仅能从超链接编辑器识别记录的情况。
- 左右往返切换与上一条 / 下一条独立动作，覆盖原生延迟展开和自动聚焦；分别验证语音接入开启及关闭。
- 手动菜单收起、原生评论按钮收起和发送后自动收起，均不会被后续重绘撤销。
- 同记录重绘保留主动展开；上一条记录的异步收起失败，不会解除下一条记录的保护。

真实飞书复验：已确认页面载入 v1.5.1，在专用虚构演示表的三条记录之间完成 20 次有效左右切换。每次核对记录 ID 确实变化，并同时检查两种原生评论编辑器布局的可见性；覆盖初始收起 6 次、主动打开再收起后 6 次、主动打开后切换 8 次，目标记录均保持收起。

另通过语音接入使用的输入位置键入 7 个测试汉字，确认自动展开并完整进入评论草稿，未发送；清空本轮测试文字后，空框 Backspace 保持输入，随后主动收起正常。本轮没有重新使用实体麦克风，也没有重新验证发送操作；组合输入和发送后收起的自动检查继续通过。原有草稿页面未刷新。

## v1.5.0 历史验证

## 自动检查

146 项自动检查通过；manifest、21 个运行文件、语法、图标、资源引用与安全策略检查通过。

本次覆盖：

- 原生 Backspace 在空评论和普通文本框中保持输入；快按、慢按、长按及删除最后一个字符后均不退出。
- 自定义删除组合键只删除，不把组合键字符写入输入框；非输入状态才逐层返回，长按不会跨层关闭。
- 菜单只展开或收起评论，保留草稿；展开后不进入评论输入。OK 可明确进入字段或评论输入。
- 会议中首次打开记录详情时，收起飞书默认展开的评论；覆盖在进入全屏过程中打开详情、原生自动聚焦、延迟出现和重绘再次展开。字段浏览不会解除默认收起；主动打开评论、正在输入和已有草稿时保留用户操作，从列表主动打开评论时保持展开。
- TV 主动退出当前窗口的全屏，覆盖多个会议标签页、扩展重载导致临时记录清空、原先已全屏和系统动画异步完成；窗口退出失败时保留会议布局供重试。导航、刷新和关闭标签页的自动清理保留原有全屏归属规则。
- 发送确认后按配置延时收起评论；覆盖关闭功能、立即收起、小数延时和 0–60 秒边界。发送未确认、期间出现新草稿或开始语音、手动重新展开、切换记录、退出会议时不误收起；修改开关或时间会取消当前待收起操作。
- 语音接入等待输入法的组合输入结束，保留中间修正，避免重复插入；已有评论草稿按原样追加。
- 本机曾出现可信文字输入后，结束事件被标记为不可信的情况。只有在已有可信组合输入、文字未被替换时才接受该结束信号；后续新的识别输入会继续等待完整结果。
- 页面暂时失焦、回到原记录后，会恢复接入未完成的文字；写入失败、进入其他字段或切换记录时不会自动写入。
- 被动接收就绪时仍可上下浏览字段，OK 进入字段后保留原生编辑；正在编辑其他字段时不重定向输入。
- 真实飞书在打开详情时可能先聚焦卡片外层的模态抽屉；在这一状态也准备接收，同时不抢占无关对话框的焦点。
- 接收期间保护记录、视图和发送动作；记录被外部更换、焦点转到其他字段或写入失败时保留原文，不写入另一条记录。
- 原生编辑器拒绝或撤回 DOM 插入时，不清空接收备份；失败不会自动重复写入。
- 默认关闭、配置迁移、未保存设置、取消识别、直接输入、粘贴和不可信事件处理。

既有缩放、Home / 电源、原生快捷键、字段导航、配置复制、草稿保护及会议恢复继续通过。

本地原型和模拟页使用虚构记录与浏览器接口替身，不调用飞书发送接口。飞书演示表使用虚构数据，使用者主动按确定发送的测试评论会真实提交；只说话不会自动发送。原型的输入事件显示识别期间持续 insertCompositionText 修正，结束时 compositionend，之后写入评论。此结果证明该输入法的纯扩展接入路线可行，不代表所有语音工具都采用相同事件形式。

本轮首次详情与 TV 修复后，另用键入文字检查了真实飞书的接收草稿路径：文字完整进入评论，未触发发送，随后清空测试草稿并收起评论；原有草稿标签页未刷新。本轮没有重新测试实体麦克风。

## 明确的行为边界

本版保留无线麦与微信输入法的 Fn 配置。Mac Chrome 过滤 Fn 事件，扩展不能知道麦克风按下的瞬间；因此在输入法完成这一段识别后自动展开评论，而非按下瞬间展开。使用者已接受这个时机，并要求不增加 Mac 组件。

语音接入默认关闭，用户开启后会在详情浏览时准备一个真实输入位置。此时直接打字也会进入评论；进入字段编辑后，文字仍写入该字段。异常时原文暂存在当前页面，可复制、核对、重试或清空。刷新前应处理未保存文字。

当前商店版为 v1.4.2。v1.5.0 已在专用虚构演示表验证上述语音和评论操作；商店审核与发布状态以 Chrome 开发者后台为准。

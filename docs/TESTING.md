## v1.2.0 真实飞书验收

使用者重新加载扩展、刷新飞书页面后，在 Mac Chrome 的实际多维表格中验证：

- TV（Control + Shift + 9）进入会议后，全屏生效、侧边栏折叠；文档路径、分享和自动化所在的顶部栏高度从 64 像素变为 0，表格内容顶部由 y=64 移到 y=0。
- 使用与遥控映射相同的 Control + Shift + 加减键，在主界面连续 8 次放大到 180%，再连续 8 次缩小回到 100%。评论输入框聚焦时重复同样的 16 次按键，结果一致，未出现漏计。
- 详情向下导航依次停靠字段。普通文本中的网址不增加额外停靠点；“超链接”类型的 GitHub 字段按 Enter 后，新标签页地址与该字段链接一致。
- 菜单（Command + 反斜杠）打开评论并聚焦空输入框。四个方向键保持评论输入焦点，没有切换记录；三次 Backspace 依次退出输入、收起评论、关闭详情。
- 原生 Command + R 触发了可观测的页面重新加载，会议开启和关闭时均可用；会议中刷新后继续隐藏顶部栏、保持侧边栏折叠。
- 退出会议恢复原来的侧边栏状态及 64 像素顶部栏。三秒后提示栏的 hidden=true、计算样式 display=none、高度为 0，确实不再占据页面。
- 验收结束恢复 100% 缩放和非会议模式，关闭仅为测试打开的链接标签页。

# v1.4.1 验证记录

日期：2026-10-23

## 自动检查

77 项自动检查及运行资源检查通过，覆盖以下变化和既有功能回归：

- 空输入框单按保留焦点，500 毫秒内两次独立按下只退出输入；之后单按收起评论、关闭详情。慢速第二次重新计时。
- 删除最后一字不计入双击；长按或缺少松键事件不能连续退出。输入、焦点切换、鼠标、选词、失焦或其他按键会取消确认。
- 原有自定义缩放队列仍完整累计快速输入；原生开关默认关闭。开启后按键直接交给 Chrome，扩展不拦截、不发送自定义缩放请求，关闭后恢复原自定义键。
- 浏览器原生缩放通知只更新会议提示栏，不发起第二次缩放，支持 Chrome 大于 250% 的档位。较早回包不会覆盖较新的比例。
- 项目更名兼容旧配置文件和既有自定义键；不更改已加载扩展的本地目录。
- Home / 电源、草稿保护、方向键、详情导航、全屏恢复及提示栏计时继续通过原检查。

## 实体设备反馈

使用者已明确确认：快速连按失效由遥控映射软件造成，并已在映射软件中解决，要求恢复最初的缩放方案。因此最终保留 Control + Shift + 加减号和自定义步长；不将此前自动检查描述为解决了硬件映射问题。

使用者重新加载 v1.4.1 并刷新飞书后，明确确认「双击返回符合预期」。本次双击返回已有自动检查与真实页面使用者确认；v1.3.0 电源跨标签页刷新也已经使用者确认。

# 多维表格控制助手 v1.5.1

修复在记录详情中左右往返切换时，评论偶发自动展开的问题。

飞书可能复用同一个详情卡片展示不同记录。此前，扩展将主动展开评论的状态记在卡片上，且收起时没有重置这项状态；后续记录加载或重绘可能因此重新显示评论。本版按数据表和记录识别当前详情，并明确记住收起操作。

- 切换到另一条记录时，评论默认收起，不继承上一条记录的展开状态。
- 菜单收起、返回收起和发送后自动收起，均覆盖后续飞书重绘。
- 同一条记录重新渲染时，保留主动打开的评论与草稿。
- 菜单、语音输入和确认发送的既有交互保持兼容，未增加权限。

155 项自动检查通过，包含新增 9 项评论切换与重绘检查。真实飞书演示表中另完成 20 次有效左右切换，覆盖三条记录和主动评论后再切换的场景；键入文字接入草稿及空框删除也已复验。完整验证范围见[验证记录](TESTING.md)。

从本地版升级时，在原文件夹更新后重新加载扩展，并刷新没有未发送草稿的飞书页面。商店版需等待新版本通过审核并发布后更新。

# 多维表格控制助手 v1.5.0

v1.5.0 把麦克风、菜单和返回键的分工理顺，并让发送后的评论收起行为可以按会议节奏调整。

## 本次更新

- **只按麦克风就能接入评论草稿**：可选开启「麦克风 · 语音接入评论」，保留无线麦与微信输入法原有的 Fn 配置。浏览详情时说话，输入法完成这一段识别后，自动展开评论并写入最终文字。已有草稿会追加，发送仍由你按确定完成。
- **菜单只控制评论显示**：展开时不激活输入框；按确定先进入输入，再按一次发送。收起、重新展开会保留草稿。
- **输入中的返回键始终只删除**：无论空框、双击或长按，都不会退出输入；只有在输入框外才逐层返回。菜单可收起评论，Esc 可单独退出输入。
- **自动收起可配置**：发送确认成功后，默认等待 1 秒收起；可关闭，或设为 0–60 秒，支持小数。0 秒表示立即收起。期间开始新的输入或手动操作评论，会取消本次收起。
- **详情与全屏更稳定**：首次打开记录及飞书延迟重绘时，默认评论保持收起；主动评论和已有草稿仍受保护。TV 主动退出会退出当前 Chrome 窗口全屏，其他会议标签页或扩展重载不再阻止退出。

## 安装与升级

从 [Chrome 商店](https://chromewebstore.google.com/detail/cajpidagedciogaoeadahcaomockfkah)安装的用户，会在新版本审核通过并发布后收到更新。GitHub 正式 ZIP 可直接下载、解压并通过「加载已解压的扩展程序」安装；上传商店时使用这个 ZIP，不要使用 GitHub 自动生成的源码 ZIP。

升级或切换安装方式前可导出配置，避免同时启用商店版和本地版。普通自定义按键会保留；Home 与电源的跨标签页组合键由 Chrome 单独管理，需要在 Chrome 扩展快捷键页核对。安装或更新后刷新飞书页面，并先处理未发送草稿。

语音接入默认关闭，需主动开启。它接收已有输入法输出的文字，不录音、不提供语音识别，也不能检测 Fn 按下的瞬间。浏览详情时直接打字也会进入评论；编辑字段时先按确定。无需增加 Mac 组件或扩展权限。

## 验证与适用范围

146 项自动检查通过，另已在 Mac Chrome、无线麦与微信输入法、专用虚构飞书演示表中验证主要流程。覆盖详情与字段浏览、菜单与返回、草稿保留、语音接入及 TV 全屏退出；完整范围见[验证记录](TESTING.md)。

当前主要支持表格视图和标准记录卡片；看板、甘特、日历及自定义卡片尚未完整适配。所有执行代码随包提供，没有开发者服务器、录音权限或新增站点权限。

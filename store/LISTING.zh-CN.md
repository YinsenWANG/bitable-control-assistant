## 名称

飞书会议遥控器

## 简短说明

为飞书多维表格提供可自定义的会议遥控快捷键：浏览记录与字段、操作链接、输入评论和全屏演示。

## 类别与语言

- 类别：工作效率（Productivity）。如果后台要求子类别，选择最接近会议或工作流程的类别。
- 默认语言：简体中文。

## 详细说明

把屏幕留给内容，把操作交给遥控器。

投影开会时，用一个 TV 键将飞书多维表格切换为会议视图：全屏显示、自动折叠数据表侧栏、隐藏文档路径与分享等顶部控件。退出会议后恢复原来的布局，底部提示三秒后消失。

用遥控器推进讨论
• 列表中上下切换记录、左右切换视图；详情中上下浏览字段、左右切换记录。
• 长文本先滚动到边界，再移动到下一个字段。
• 仅“超链接”类型字段中的链接单独落焦，按确认在新标签页打开，普通正文不会出现大量网址焦点。
• Home 从其他标签页回到正在开会的表格；电源通过 Chrome 命令刷新当前标签页，GitHub 等网站也适用。
• 音量加减用于连续缩放，让远处的参会者看清内容。

讨论结论随手记录
• 菜单键展开评论并自动聚焦输入框，再次按下收起。
• 兼容现有系统或第三方语音输入法；本扩展不录音，也不提供语音识别。
• 输入时方向键仍用于移动光标和选词。返回键有文字时删除左侧字符，空框时逐层返回。
• 收起评论保留草稿；切换记录、视图或关闭详情前检查未发送的评论。

按你的习惯配置
• 每项组合键可以自定义，并提供复制、按键检测与配置导入导出。
• Home 与电源在 Chrome 扩展快捷键中单独配置，其余动作在扩展设置页录入。
• 部分动作可切换为飞书或 Chrome 原生快捷键。
• 无需预先填写固定表格地址，自动识别不同租户的飞书多维表格。

使用要求与范围
需 Chrome 111 或更新版本，以及相应飞书页面访问权限。遥控器需由现有映射软件转换为键盘按键，本扩展不连接蓝牙。当前以表格视图和标准记录卡片为主，看板、甘特、日历和自定义卡片尚未完整适配。刷新遵循浏览器原生行为，请先处理未保存内容。

隐私与开源
无开发者服务器、广告或分析统计，不上传表格数据。配置和会议定位信息仅在本机处理；评论由用户已登录的飞书发送。跨标签页刷新只使用标签页 ID，不读取其他网站内容。MIT 开源。

本工具独立开发，与飞书及其运营方没有隶属关系。商店中的布局示意图使用虚构数据，实际界面以飞书为准。

## Privacy practices：单一用途

为飞书多维表格的投影会议提供可自定义的键盘和遥控操作，包括记录与字段浏览、评论输入、全屏演示，以及浏览相关链接时返回会议和刷新当前标签页。

## storage 权限理由

在本机保存用户自定义快捷键、原生快捷键开关、缩放步长和显示偏好；在浏览器会话中暂存最近会议标签、窗口及全屏恢复状态。数据不上传开发者服务器。

## 主机权限理由

飞书多维表格分布于不同租户的 *.feishu.cn 域名。内容脚本仅匹配 Base、Wiki 和 Base 分享路径，检测多维表格并操作用户已经有权访问的可见控件、字段和评论框。站点权限还用于识别会议表格标签，以便 Home 返回。不会访问其他网站的页面内容；电源刷新使用 Chrome tabs.reload，只使用标签页 ID，无需其他站点权限。

## 是否执行远程代码

否。所有执行代码随扩展打包，不下载或执行远程脚本，不使用 eval、远程代码托管服务或开发者后端。

## 数据使用披露

根据本版代码处理的内容，披露以下类别，并与后台当前的分类名称对应：

| 类别 | 用途和范围 |
| --- | --- |
| 网站内容 / Website content | 在飞书页面中识别记录、字段、链接、可见控件与评论草稿，用于导航和草稿保护。 |
| 网络记录 / Web history | 仅最近主动开启会议的表格 URL，暂存在 Chrome 会话中，用于 Home 返回；不调用浏览历史 API。 |
| 用户活动 / User activity | 在飞书页面和扩展设置页处理快捷键；仅在检测区显示内存中的按键日志。 |
| 个人通信 / Personal communications | 用户在飞书原生评论框中主动输入和发送的评论；不复制到开发者服务。 |

以上数据只为所述核心功能在本机处理或由用户正在使用的飞书服务处理，不向开发者上传，不出售，不用于广告、信用评估或与单一用途无关的目的。不要勾选“完全不处理用户数据”：Chrome 要求披露仅在本机处理的数据。

后台的数据使用承诺应如实确认：不出售或转移用于未批准用途、不用于与单一用途无关的目的、不用于信用评估或放贷。
